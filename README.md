# Lab2 ToDo

Консольное ToDo-приложение на языке Dart, созданное в рамках лабораторной работы №2. Позволяет добавлять, просматривать, отмечать выполненными и удалять задачи.

## Как запустить

1. Клонировать репозиторий: `git clone https://github.com/Demor865/Dart_Lab2.git`
2. Перейти в папку: `cd lab2_todo`
3. Установить зависимости: `dart pub get`
4. Запустить: `dart run`

1. Создание классов, полей и конструкторов в Dart.
2. Работа с именованными параметрами и ключевым словом `required`.

5. Подключение и использование внешних пакетов из pub.dev (на примере `ansicolor`).

## Ответы на вопросы

**1. В чём разница между полем класса и обычной переменной в функции?**
Поле класса живет вместе с самим объектом и к нему можно обращаться из любых методов этого класса. А обычная переменная внутри функции (локальная) существует только пока эта функция выполняется. После завершения функции она удаляется, и из другого места программы к ней достучаться нельзя.

**2. Что такое конструктор и зачем он нужен?**
Это специальный метод, который срабатывает автоматически в момент создания объекта. Он нужен для того, чтобы сразу задать начальные значения полям (например, id и title). Без него пришлось бы сначала создавать объект, а потом вручную заполнять каждое поле, что неудобно.

**3. Зачем нужен @override перед toString()? Что будет если его убрать?**
Эта аннотация как бы говорит компилятору: "я сейчас переопределяю метод родительского класса". Если ее убрать, программа всё равно запустится, но мы потеряем защиту. Если мы случайно опечатаемся в названии метода, компилятор просто подумает, что это новый метод, и не выдаст ошибку. А так он сразу подсветит проблему.

**4. Чем статическое поле static int \_counter отличается от обычного поля? Сколько копий этого поля существует в программе?**
Обычное поле принадлежит каждому объекту отдельно (у каждой задачи свой id). А статическое поле принадлежит самому классу и является общим для всех объектов. В памяти существует ровно одна копия этого поля на всю программу, сколько бы объектов мы ни создали.

**5. Что означает нижнее подчёркивание в \_counter?**
В Dart нижнее подчеркивание перед именем делает переменную приватной. Это значит, что к ней можно обращаться только внутри того файла (todo.dart), где она объявлена. Из других файлов проекта к ней напрямую уже не обратиться.
